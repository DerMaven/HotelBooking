# HotelBooking - сервис для брони номеров в отелях (WIP - В РАЗРАБОТКЕ)

Данный проект представляет собой бэкенд для сервиса, который работает с бронью отелей и оценками гостей. Проект создан на основе Spring Boot, с использованием языка Java 17 и системы сборки проектов Maven. В зависимости проекта добавлены следующие сторонние библиотеки: spring-boot-starter-web, spring-boot-starter-jdbc, Lombok, Hibernate, Redis, Docker, JUnit 5.

Информация об отелях, номерах, турах и рейтингах хранятся в PostgreSQL и Redis.

Проверка нагрузки и отлеживание производительности будут реализованы чуть позже, с помощью Apache JMeter и Prometheus.

## Функционал
В данном проекте на данном этапе реализованы следующие функции:

* CRUD-операции над отелями, выбором номеров по тарифам, датам и тд.
* Получение лучших отелей в городе
* Оценка каждого отеля и номера
* Добавление и удаление гостя из списка друзей
* Получение списка друзей гостя
* Получение списка общих друзей между двумя гостями

## Как запустить проект?

1. Загрузить проект из ветки "main" по ссылке на скачивание;
2. Извлечь содержимое архива;
3. Вы должны иметь установленный Docker и PostgreSQL 18.6
4. Запустите Docker file
5. Запустите в терминале команду
``` bash
docker-compose up
```
6. Наслаждайтесь сборкой! :)

> **Note**
> * Перед началом работы убедитесь в работоспособности двух БД (Redis и PG) после сборки через docker-compose, выполнив тест соединения (в DataGrip или IntelliJ IDEA при создании базы данных нажмите "test connection")
> * Проверьте, что все зависимости и сторонние библиотеки, указанные в `pom.xml`, загружены на ваш ПК
> * Убедитесь, что у вас установлена Java 17, необходимая для запуска программы
